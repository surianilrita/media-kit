# Media kit · Rita Suriani

Site estático em um único arquivo: `index.html`.

- **Trabalhos:** lista `TRABALHOS` no fim do arquivo. Para adicionar um, copie uma linha e troque o texto.
- **Perfis e seguidores:** lista `PERFIS`, campo `seg`.
- **Áreas (os botões do topo):** lista `AREAS`.

Publicado pelo Netlify a partir da branch `main`. Qualquer mudança aqui vai para o ar sozinha.
